# 인명여고 1학년 익명게시판 (정보보안 실습용)

정보보안 전문가 진로체험 수업에서 쓰는 **교육용 가상 게시판**입니다.
학생들은 게시판에 올라온 시험시간표 이미지에서 출발해 파일 시그니처, 파일 카빙, Base64 디코딩, 네트워크 패킷 분석을 차례로 체험합니다.

- 게시판: https://anzinius.github.io/inmyong/
- 실습 자료실: https://anzinius.github.io/inmyong/files.html

## 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `post.html`, `write.html`, `static/` | 정적 게시판 (HTML/CSS/JS, 서버·DB 없음) |
| `assets/` | 게시글 첨부 시간표 이미지 원본 |
| `files.html`, `files/` | 실습 자료: 워밍업 이미지, 가상 교무실 네트워크 기록(PCAP) |

## 알아 둘 점

- 게시판의 모든 글, 이미지, 네트워크 기록은 **수업을 위해 만든 가상 자료**입니다. 실제 학교, 계정, 서버, 시험 자료와 관련이 없습니다.
- 글쓰기, 댓글, 공감은 각자 브라우저의 저장소(localStorage)에만 남고 다른 사람에게 보이지 않습니다.
- 2·3학년 게시판의 접근 제한은 화면 연출이며, 실제 인증 기능이 아닙니다.
- 첨부 이미지는 원본 그대로 받아야 실습이 됩니다. 캡처하거나 다른 형식으로 다시 저장하지 마세요.

## 실습 약속

배운 기술은 이 게시판과 제공된 파일에서만 사용합니다. 허락 없이 실제 웹사이트, 학교 시스템, 다른 사람의 계정이나 기기에 시험하는 것은 「정보통신망법」 위반입니다.
